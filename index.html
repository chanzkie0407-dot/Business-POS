🧩 MAIN FEATURES

  • ✅ Sales / Checkout: Category filter, barcode scan/search, Senior/PWD 5% discount (requires ID+Name), Cash / E-Wallet / Split Payment
  • ✅ Shift Management: Open shift with ₱1,000 float → Close shift REQUIRES full denomination. Remittance amount HIDDEN from Cashier.
  • ✅ Requests: Void, Cash In/Out, Product Out — all PENDING until Admin approval. Notifications sent to Admin.
  • ✅ Inventory: Stock updates ONLY via approved sources. Admin sends count request → Cashier submits → System compares → Shortage traced → Unfound shortages go to Variance Report.
  • ✅ Reports: Daily Sales, Date Range, Shift Log, Void Log, Variance Report (Admin-only)
  • 💬 Chat: Cashier→Admin; Admin↔SP. SMS/Email alert if Admin offline.
  • 🔌 Offline Ready: Works without internet. Auto-syncs when restored. Manual Sync button available.
  • ⚠️ Auto-Logout: System auto-logs out after 10 minutes of inactivity.
  • ⚠️ Service Expiry: 7-day free trial. System LOCKED until renewed by SP manually.
  • 🔑 Password Rules: First login forces password change (min 6 chars). SP changes Admin password; Admin changes Cashier password; SP changes own password.
